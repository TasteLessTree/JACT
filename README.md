# Java Automated Compiler Toolkit

> Another tool for C compiling.

A tool to build simple C projects, written in Java (21) and built with Gradle.

## Compilation

On Linux:

```bash
chmod +x gradlew
```

Then compile with gradlew (or gradlew.bat on Windows):

```bash
./gradlew jar
```

Output on:

```text
app/build/libs/jact.jar
```
